# 第三阶段：样本库建设与弱监督校准计划

## 一、阶段目标

第三阶段目标不是马上训练模型，而是建立可持续积累的剧本审核样本库。

系统需要把以下数据保存到统一结构中：

1. 原始剧本文本
2. LLM 内容解析结果
3. LLM 分项评分结果
4. 可视化分析数据
5. Markdown 审核报告
6. 训练样本 training_sample
7. 轻量人工反馈
8. 公司已有业务表现数据

最终目标是形成可用于后续统计分析、模型训练和平台接入的数据基础。

## 二、当前不做的事情

当前阶段暂不做：

1. 不做大规模网络爬虫
2. 不训练大模型
3. 不微调 LLM
4. 不做多模态分析
5. 不要求人工逐条改剧本
6. 不把模型评分直接作为上线决策

## 三、数据优先级

### 最高优先级：公司已有版权剧本

需要确认：

1. 是否有完整剧本文本
2. 是否有分集大纲
3. 是否有人物设定
4. 是否有上线表现数据
5. 是否有修改前后版本
6. 是否允许用于内部模型训练和算法分析

### 高优先级：平台生成剧本

需要记录：

1. 生成时间
2. 生成模型版本
3. 提示词版本
4. 审核结果
5. 修改记录
6. 是否上线
7. 上线后表现

### 高优先级：业务表现数据

需要字段：

1. 是否上线
2. 上线平台
3. 上线时间
4. 完播率
5. 有效播放率
6. 互动率
7. 点赞率
8. 评论率
9. 转发率
10. 收藏率
11. 追更率
12. 账号等级
13. 投流情况
14. 推荐资源位

## 四、弱监督校准方式

由于当前没有大量专业人工标注，采用弱监督方式积累样本。

弱监督来源包括：

1. LLM 初始评分
2. 公司已有真实表现数据
3. 少量人工抽检
4. 修改前后评分变化
5. 是否最终上线
6. 上线后的相对表现

人工只做轻量判断，不要求写剧本修改方案。

轻量判断包括：

1. 模型评分是否偏高、偏低或基本准确
2. 问题标签是否大体正确
3. 修改建议是否有参考价值
4. 该样本是否适合进入训练集

## 五、后续训练条件

当样本达到以下规模后，再考虑训练模型：

50—100 条样本：用于校准评分规则和提示词。

100—300 条样本：用于统计分析和规则优化。

300—500 条样本：可尝试训练问题标签分类模型。

1000 条以上样本：可尝试训练剧本等级分类模型和分项评分预测模型。

3000 条以上样本：再考虑更稳定的市场适配性预测模型。

## 六、推荐训练顺序

第一步：问题标签分类模型。

第二步：剧本等级分类模型。

第三步：分项评分预测模型。

第四步：结合真实业务表现做相对表现预测。

第五步：在数据量足够时，再考虑微调剧本审核 LLM。

## 七、当前阶段验收标准

1. 能批量处理本地 txt 剧本
2. 每个剧本都能生成 training_sample
3. 每个 visual_report 都能校验通过
4. 能记录轻量反馈
5. 能对接公司已有剧本和业务表现数据
6. 能积累 50 条以上有效样本
